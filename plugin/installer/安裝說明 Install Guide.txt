KHIMAIRA __VERSION__ / Native MIDI Generator

Mac: macOS 12.3+。AU MIDI FX / VST3 / Standalone。
Windows: Windows 10/11 x64。VST3 / Standalone；介面需要 WebView2。

Logic Pro：
1. 在軟體樂器軌的 MIDI FX 槽選 Audio Units > KHIMAIRA > KHIMAIRA 1.2 MIDI FX。
2. 後面的 Instrument 槽載入 Serum 或任何 Logic 音源。
3. HOST 開啟時跟隨 DAW PPQ/BPM，從專案第 1 小節對齊並循環。
4. DAW 停止時按 PLAY 原生試聽；STOP 停止，再 PLAY 從頭。外掛 BPM 由 DAW 決定。
5. 要錄下輸出，在外掛下方 MIDI FX 槽選 Record MIDI to Track Here，再錄音。

VST3：
以樂器載入 KHIMAIRA 1.2；它只產生 MIDI，音訊輸出為靜音。
在另一條樂器軌接收此軌的 MIDI，載入音源並開啟監聽。
Ableton Live：第二條 MIDI 軌的 MIDI From 選 KHIMAIRA 所在軌，第二個來源選 KHIMAIRA，Monitor 選 In。
實際完成的 DAW 驗收以 docs/plugin-1.2/README.md 為準。

DRAG MIDI：拖曳底部按鈕到 DAW 軌道；單擊可另存 MIDI。
沒有內建鋼琴。Standalone 用於編輯、產生及匯出 MIDI，不提供內建聲音。
進階設定按 ADVANCED 展開；主要控制項在預設與最小視窗內完整顯示。
和弦與設定存在 DAW 專案；播放中修改在下一小節套用。

安裝位置：
AU: /Library/Audio/Plug-Ins/Components/KHIMAIRA 1.2 MIDI FX.component
VST3 Mac: /Library/Audio/Plug-Ins/VST3/KHIMAIRA 1.2.vst3
App: /Applications/KHIMAIRA 1.2.app
VST3 Windows: C:\Program Files\Common Files\VST3\KHIMAIRA 1.2.vst3
1.2 使用新的識別碼，不覆蓋 0.3 / 1.1 的專案實例。

English
Logic: insert KHIMAIRA 1.2 MIDI FX in the MIDI FX slot, then load Serum or a Logic instrument below it.
VST3: load KHIMAIRA 1.2 as an instrument and route its MIDI output to a second instrument track.
HOST follows the project PPQ/BPM. PLAY auditions using a native audio-callback clock at host tempo;
STOP stops, then PLAY starts at the beginning. Changes switch at the next bar with note-offs.
Drag MIDI to a track, or click to save a MIDI file. No piano or other audio engine is included.
Standalone is a MIDI chart editor/exporter. See the validation report for tested host coverage.
