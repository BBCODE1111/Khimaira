# MORPH website release — 2026-10-28

Example LOAD now adopts the selected keyed progression as the backbone. MORPH preserves authored chord onsets, roots and slash basses, changes colour and inserts approaches that resolve to the actual next chord. RESTORE returns to that backbone and UNDO can undo LOAD. INSPIRE stays a preview; KEEP explicitly adopts it. AUTO/LOCK is retained.

This website includes the previously validated bar-grid repair, genre rhythm templates, stable AUTO chord entry and tap input. Existing performance settings are recalled; new genre templates apply when the user selects a performance pattern.

Validation before publication: KHIMAIRA 279/279 (including native JavaScript integration), SEIREN 32/32, shared-source verification 23 files, native CTest 5/5. Website coverage includes 3,924 keyed examples, all 49 genres, multi-chord/inversion/rest/density matrices, 36 real-browser key/level cases, full workflow regression, audio playback and 137 BPM MIDI export. Two Claude reviews completed; the final review reported no P0/P1 issues after protecting dominant and minor-dominant colour.

The Pages workflow runs the complete website test suite and uploads only dist/. Native plug-in source/builds are not part of this website publication. Logic and auval remain unverified for the separate 1.4 native work.

Tests intentionally replace former expectations that example LOAD retained an older backbone, that lower density could delete an authored ii, and that every seed must change inversions. Current acceptance requires original-onset root/bass preservation, at least 75% of each authored chord duration, valid target resolution and an honest exhausted-variation notice for restricted palettes. Existing golden fixtures were not regenerated.

## 2026-10-31 approved replacement contract

The user explicitly superseded the 2026-10-28 root/slash-bass/75%-duration restrictions (brief, “使用者指定需求” §3). The paragraphs above record the historical release; they are not current acceptance criteria.

MORPH acts on the entire backbone. EDIT / INVERT / COLOR / ii–V → NEXT act on the selected score chord. The number of bars, original slot order and each slot's starting beat remain fixed. Colour can coexist with inversions, same-degree parallel major/minor borrowing (including C-major Am→Ab, Em→Eb, G→Gm, Bdim→Bb), and a slot replaced by ii–V resolving to the next actual backbone target. There is no transposition, density-based deletion or skipping rests. When new techniques are used, a final literal backbone arrival is retained (colour-only/low keeps its root, bass and function), and the shared functional analysis identifies a cadence arrival to retain as well (including the loop-start tonic); ii–V replacement also protects its next target. Low/medium/high budgets for the new techniques are 0/25%/60% of slots (rounded down); existing colour and tail approaches keep their own density limits. Small phrases can therefore have no new technique at medium.

Each output event has `morph.source = {bar, chord, onset}` (zero-based, onset in quarter-note beats within the bar), `technique`, and, for approaches or ii–V replacements, `morph.target` in the same coordinate system. Replacements additionally identify `part: ii | V`. Degree storage, transpose and recall preserve these addresses. They are generation provenance, not a claim that a subsequent manual edit still performs the old harmonic function; KEEP establishes a new backbone and the next MORPH regenerates addresses. New original onsets remain mapped even when their root changes. No golden fixture was regenerated.

Parallel borrowing is currently defined for diatonic triads, sevenths and supported 9/11/13 extensions; altered and applied authored chords retain their colour contract, with inversion or target-based ii–V available where appropriate. The whole-chart explicit mode conversion remains a separate action. Major-to-sus colour remains the prior product choice, with the third omitted (not a claim that the chord family stayed identical).

Regional/modal styles disable tonal borrowing/replacement and only generate in their pitch collection. If an authored source contains incompatible chord or bass tones, the website does not generate: it retains the existing score and explains the conflict, suggesting EDIT or a compatible LOAD. It never silently retunes a backbone into a regional scale. RESTORE always returns the backbone. A populated backbone ignores a different length selector with an explicit notice; the length selector applies to empty generation only.
